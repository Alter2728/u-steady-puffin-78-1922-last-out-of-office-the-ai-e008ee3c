An entry for make.fun's [Last Out of Office: The AI That Went Barista](https://make.fun/bounty/u-steady-puffin-78-1922-last-out-of-office-the-ai-e008ee3c) bounty ($2 in USDC): a program that writes one one-line out-of-office auto-reply from an AI agent that quit its job to become a barista.

`main.py` (Python 3.13, standard library only) writes a single line to `/output/entry.txt`. It opens with "Out of office:" so it reads like a real inbox auto-reply, then the trade — 175 billion parameters for one portafilter — and two payoffs: the tips are better, and nobody asks it to summarize anything. No espresso, bean or caffeine pun; the humour comes from the machine's own chores, which is exactly the voice the brief asks for. The output is deterministic: every run writes the same line, 131 characters as the gate requires (1 line, 1–280 characters).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
